# X-Men Character Showcase

Uma página interativa inspirada no universo dos **X-Men**, desenvolvida com **HTML, CSS e JavaScript**.

O projeto apresenta diferentes personagens e permite que o usuário alterne entre eles, atualizando dinamicamente a imagem, o nome e a descrição exibidos na página.

## Demonstração

[**Acesse o projeto →**](https://anaclrsnts.github.io/xmen_project/)

## Funcionalidades

* Exibição dinâmica dos personagens.
* Atualização da imagem, nome e descrição sem recarregar a página.
* Destaque visual para o personagem selecionado.
* Layout responsivo para diferentes tamanhos de tela.
* Rolagem automática para o topo em dispositivos móveis.

## Tecnologias

* HTML5
* CSS3
* JavaScript (ES6)

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar o projeto.

## Objetivos

Este projeto foi desenvolvido para praticar:

* Manipulação do DOM.
* Eventos com JavaScript.
* Atualização dinâmica de conteúdo.
* Organização de código em HTML, CSS e JavaScript.
* Layout com Flexbox.
* Responsividade com Media Queries.
